# 📊 Exploratory Data Analysis (EDA) on Social Media Content

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Social Media Content Dataset using Python. The main objective is to analyze social media engagement metrics and understand the relationship between content types, likes, views, and reach.

The project uses data visualization techniques to identify patterns, distributions, and correlations in social media content.

## 🎯 Objectives
- Analyze different types of social media content.
- Understand the distribution of likes.
- Compare likes across different content types.
- Analyze the relationship between reach/views and likes.
- Identify correlations between numerical variables.
- Find the top 10 posts based on likes.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 📂 Project Workflow

### 1. Data Loading
- Imported the required Python libraries.
- Uploaded the dataset using Google Colab.
- Loaded the dataset using Pandas.

### 2. Data Preprocessing
- Removed duplicate records.
- Handled missing values by replacing them with zero.
- Cleaned column names by removing spaces and converting them into lowercase.

### 3. Data Visualization and Analysis

**Content Type Distribution**
- Visualized the distribution of different content types using a Count Plot.

**Distribution of Likes**
- Used a Histogram with KDE to understand the distribution of likes.

**Likes by Content Type**
- Compared the number of likes across different content types using a Bar Plot.

**Reach/Views vs Likes**
- Used a Scatter Plot to analyze the relationship between reach or views and likes.

**Correlation Analysis**
- Created a Correlation Heatmap to understand relationships between numerical variables.

**Top 10 Posts by Likes**
- Identified and visualized the top 10 posts based on likes.

## 📈 Key Analysis
The project explores:
- Content type frequency.
- Distribution of social media likes.
- Engagement comparison between content types.
- Relationship between reach/views and likes.
- Correlation among numerical features.
- Top-performing posts based on likes.
